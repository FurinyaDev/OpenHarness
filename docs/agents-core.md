# Project agent instructions

- Read the project README and the local guidance for the task. Find build, lint,
  test, and delivery commands in project documentation, task scripts, or CI.
- Confirm scope, acceptance criteria, and dependencies in the existing task
  system. Preserve other work and follow project permissions and branch rules.
- Use the [engineering guide](https://github.com/FurinyaDev/OpenHarness/blob/OPENHARNESS_REVISION/docs/engineering.md)
  for change planning, guardrail recipes, and review. Link project-specific
  architecture decisions and commands here as the project needs them.

## Verification

- Run the applicable project commands. Record the candidate and base, what ran,
  results, and any checks still pending. Follow the project's review and CI gates.
- Record required human, platform, or device evidence against the same candidate.
  Keep the applicable acceptance and delivery state pending until it exists.
